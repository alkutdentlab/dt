# مختبر الكوت لصناعة الأسنان | Al-Kut Dental Lab Website

مشروع موقع إلكتروني تعريفي حديث واحترافي لمختبر الكوت لصناعة الأسنان، مصمم للرفع المباشر والاستضافة عبر **GitHub Pages**.

## 🌟 المميزات
- **تصميم متجاوب بالكامل**: متوافق مع كافة أحجام الشاشات (الهواتف، الأجهزة اللوحية، والشاشات الكبيرة).
- **هوية بصرية متناسقة**: ألوان مخصصة (التركوازي/التيركواز، الذهبي النحاسي، والأبيض) تعكس النظافة والاحترافية الطبية.
- **دعم اللغة العربية**: دعم كامل لاتجاه النص من اليمين إلى اليسار (RTL) واستخدام خطوط عربية حديثة (Cairo & Tajawal).
- **جاهزية سريعة**: بدون أي تعقيدات أو مكتبات ثقيلة، ويعتمد على HTML5, CSS3, JavaScript فقط.

## 📁 هيكلة الملفات
```text
alkut_dental_lab/
├── index.html        # الهيكل الرئيسي والمحتوى
├── style.css         # التنسيقات والألوان والتجاوب
├── script.js         # التفاعلية والقائمة الجانبية للهاتف
├── logo.png          # شعار المختبر الرسمي
├── about-us.jpg      # صورة قسم نبذة عنا
├── work1.jpg ... work6.jpg  # صور معرض الأعمال
└── work1.png ... work6.png  # صور الأقسام والخدمات
```

## 🚀 طريقة الاستضافة على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub باسم `alkut-dental-lab` أو أي اسم آخر.
2. ارفع كافة الملفات الموجودة داخل هذا المجلد إلى المستودع.
3. اذهب إلى **Settings** -> **Pages**.
4. اختر الفرع (Branch) الرئيسي `main` أو `master` واضغط **Save**.
5. ستحصل على رابط موقعك المباشر خلال دقائق!
